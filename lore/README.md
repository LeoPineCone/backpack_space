# Lore

The places of the Backpack Space world and what comes from them, so pictures, backgrounds, item ideas and
later the website stay consistent.

- `planets.json` – planets, moons, comets, belts, stations and stars. Each place has traits, the kind of life
  and things it produces, an idea for a menu background, and links to items (`items`) and heroes (`heroes`)
  that come from it. An item has at most one place of origin. Everything is `draft` until Ilja decides it.
- `graph.html` – generated by `npm run lore`: the places, heroes and items as a graph. Tap a node to see its
  details and links; open the file in any browser.

Rules:

- Edit `planets.json`, then run `npm run lore` and `npm run validate` (it checks ids, orbits and double origins).
- When a picture description gives an item a home planet (see `.claude/skills/item-art/SKILL.md`), add the item
  to that place here, or add a new place. Vary the places: the world should feel wide.
- A place's `background` is the starting point for menu backgrounds (see `docs/retention.md`).
- Repo language is English; no names or looks from existing games.
